盘面看点

指数那本账在涨，结构那本账在坏：这是"换仓换不动"的典型样子

  • 周线 vs 日线打架：一周涨 1% 以上，最后一天却跌 1% 到 4%——说明前四天在扩散、第五天在撤退，撤退日还缩量
  • 缩量的含义：放量下跌是有人换手，缩量下跌是有人直接不玩。反弹没量，就不是反弹
  • 板块顺序变了：资金从算力硬件挪到银行电力农业，不是看好它们，是先把仓位放到"不会一夜归零"的地方
🎯 一句话解读："指数不难看、账户很难看"是这个阶段的典型体感。判断换仓结束没有，别盯指数点位，盯两件事：成交能不能回到 1.9 万亿以上、光模块能不能止跌——这两条不成立，反弹都只算技术性修复。

💰 省钱

billion-context：让 Agent 在 10 万 token 窗口里跑"一个月"的会话

一个上下文压缩插件：目标是把月级长会话压进 100K 窗口，token 用量最多省 5 倍。它不是简单截断历史，而是保留任务相关结构再压缩——长跑 Agent 最贵的那笔账单刚好在这里。

三步试用法
  • 先跑一次"不装插件"的长会话，把账单记下来（这是你的基准线，没有它没法判断省了多少）
  • 装上插件，把压缩阈值调到比你平时窗口小一档，再跑同一类任务
  • 对比两件事：结果质量有没有掉、token 账单降了多少。只有两边都合格才值得长期用
💡 为什么值得试：上下文才是 Agent 的真成本，模型单价反而是小头。这类插件不改变模型能力，只改变"记住多少"——调对了，同样的钱能干更久的活。

🕹️ 自动化

agent-browser：给 Agent 一个"浏览器遥控器"，而不是一整套脚本

Vercel Labs 出的浏览器自动化命令行，Rust 写的单二进制：开页、点选、抓取、断言都是一条短命令，返回结构化结果。相比让 Agent 现场写 Playwright 长脚本，它更不容易在中途迷路。

三步试用法
  • 先拿一个本地页面试：让它打开、点一个按钮、把结果抓回来——确认链路通
  • 再换一个需要登录的页面，观察它怎么处理"没登录"这种失败——这是判断工具成熟度的最快方式
  • 最后把它接进你现有的 Agent 流程，只替换"打开网页"这一步，别一次全换
💡 为什么值得试：网页自动化最大的坑不是"点不到"，是"点错了还以为点到了"。命令短、结果结构化，意味着你更容易在每一步加校验——这才是让 Agent 干活能收尾的关键。

astryx：Meta 开源的设计系统，专门为"Agent 生成页面"准备

❓ 今日一问

"孩子近视别急着配眼镜，越戴度数越深，眼睛还会变形"——真是这样吗？

❌ 谣言 · 这个"锅"眼镜不背，不戴反而更容易加深

这是门诊里最常被家长重复的一句话，也是眼科医生最想纠正的一条。真相是：近视了不矫正，眼睛长期处于模糊、疲倦的状态，反而更容易让近视进展；科学规范地验光配镜，不但让人看清，还能减轻视疲劳、改善双眼视功能，有助于延缓近视进展。

为什么
  • 度数加深另有人负责：戴镜后近视还在涨，不是眼镜的错，是"导致近视进展的环境因素"还在持续——长时间近距离用眼、光线不足、户外时间不够
  • "时戴时不戴"更糟：只看远时戴、看近时摘，容易让双眼协调功能失衡，更容易视疲劳和进展。只有约 10% 的低度近视孩子，因眼位与调节的特殊情况可以在读写时不戴，且必须由专业机构判定并听医嘱
  • "眼睛变形"是另一回事：真正让眼球外观变化的是眼轴变长，也就是近视本身在进展，不是镜片压的；反过来，医院眼科眼外伤急诊里，受伤的几乎全是不戴眼镜的孩子
🍽️ 餐桌怎么说：妈，眼镜不是"越戴越深"，是"越不戴越容易深"。孩子看不清还硬撑，眼睛一直累着，度数才涨得快。真要防加深，办法是每天户外待够两小时、读写姿势别趴着，半年去正规医院查一次。

🧠 其一 · 认识论

你学到的成功经验，可能都来自“活着回来的人”

「幸存者偏差」：我们只看得见“回来了的”，看不见“没回来的”。而答案往往在后半部分——因为它没出声，看上去就不存在。

换个看法
  • 1943 年，美军统计返航飞机的弹孔，发现机翼最多，结论是加固机翼。统计学家沃德说反了：该加固发动机——发动机中弹的飞机根本没飞回来，压根不在样本里。
  • 成功学的书架上摆着的都是活下来的公司。同期成立、用了几乎同样办法的大多数已经死了，它们的书没人写，你也就读不到。你读到的是分母里被删掉的那部分。
  • 所以“他这么做，所以成功了”这句话，永远缺一个分母。该问的不是“成功者做了什么”，而是“做同样的事，多少人活下来了”。
💭 留给你的问题：你最近信的那条经验，分母是多少？那些没回来的人，是因为什么没回来的？

🧠 其二 · 心灵

它能答对，就等于它懂吗？

「中文房间」：塞尔 1980 年的思想实验——一个不懂中文的人待在屋里，靠一本规则手册把中文问题对成中文答案递出去。隔着门缝看，屋里的人“懂中文”。

换个看法
  • 可屋里的人一个中文字都不认识。他操作的是笔画的形状，不是意思——手册只说“看到这串，就写那串”。
  • 塞尔的意思是：计算机大概也这样，处理符号之间的关系，而“理解”是另一回事。四十年过去，反方也很硬：人和手册加在一起，也许整体就懂了呢？这场争论至今没有结论。
  • 对你有用的不是站队，而是它逼出来的那个区分：你要的是“看起来懂”，还是“真的懂”。这两件事在“能通过考试”这一层上，完全分不出来。
💭 留给你的问题：如果一样东西在所有场合都表现得像懂，你还坚持要它有“内在的理解”吗？如果坚持，是为了什么？

🧠 其三 · 因果

油价跌的不是事实，是预期——而预期会造出事实

「自我实现的预言」：一个原本不成立的判断，因为人们相信它、并照着它行动，最后真的成立了。默顿 1948 年给这种现象起了这个名字。

换个看法
  • 11 月 2 日 WTI 单日跌 7.36%，理由只有一个——伊朗称最高领袖已授权谈判。可同一天，海峡的水雷没清、油轮还在触雷。塌下去的是预期，不是供给。
  • 但预期不是空的。交易员按它下单，炼厂按它调库存，船东按它改航线；价格先变，现实跟着变。相信本身成了原因之一。
  • 银行挤兑、楼市“再不买就涨”、“这公司要完”的传言，都是同一个结构：判断 → 行动 → 行动把判断变成真的。所以这类事里，“事实”和“看法”分不干净——你以为在观察，其实在参与。

  • 代价：省掉解码，等于省掉最大的一块推理开销；但可解释性也随之下降，你看不到"它为什么这么想"
💡 为什么值得看："用文字思考"可能只是当前工程约束，不是智能的必需。这条路线如果站得住，Agent 的成本结构会被重写——但调试难度会同步上升。

🧠 记忆

《压缩记忆的局部与全局》：邻居保住了，主题却乱了

Agent 把文本压成向量存起来，通常以"每条记忆的最近邻是否保住"作为验收标准。但这篇指出：Agent 还要合并、删除、比较记忆，这些操作依赖"哪些条目离得远"。作者用两个无标签指标同时评估两端——10 个邻居的局部保真度，和覆盖 30%-50% 记忆的全局保真度。

  • 结果反差明显：每段 96 字节时，重打分的二值编码局部保真度达 0.97，却把 10.1% 的段落挪到了另一个主题；8 位 PCA 局部只有 0.77，主题错位仅 1.7%
  • 给出的界：在全局保真度区间内，误差上界与"近-远排序违背率"的平方根成正比（最多 2-2.18 倍），而该违背率与压缩的距离噪声相关性高达 0.979
💡 为什么值得看：它给了"记忆压缩到底能不能用"一个可计算的标准：光看检索命中率会高估效果。做 RAG 或 Agent 长期记忆的人，这套双端评估可以直接搬走。
