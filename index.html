美团 LongCat-2.5：1.6 万亿参数、单 token 只激活 480 亿，全程跑在国产算力上

11 月 3 日，美团 LongCat 团队发布原生多模态模型 LongCat-2.5：总参数 1.6 万亿，每个 token 只激活约 480 亿，支持 1M 上下文，主打长程智能体、视觉编程与复杂工程任务。

  • 为什么强调国产算力：针对国产加速器单卡不足 80GB 显存的限制重做了并行策略与显存配置
  • 效果：长序列 SFT 单卡吞吐量比基线提升 86%；Terminal Bench v4.0 得分 38.5
  • 对照：同一天，产业链传出 DeepSeek V5 计划用昇腾芯片做预训练——“国芯训国模”从推理走向训练
💡 解读：这条最值钱的不是参数，是那句“针对 80GB 显存重构并行策略”。它说明国产算力的短板正在被当作工程问题逐个拆解，而不是等下一代芯片。真正要观察的是：这类模型能不能在国产卡上稳定跑一个月不出事。

💾 省显存

colibri：显存不够也能跑 MoE 大模型，热的专家在 GPU、冷的从硬盘流

用 C 写的分层推理引擎，专门对付 MoE（混合专家）模型：常用的专家留在 GPU 显存里，次常用的放内存，最冷门的直接从 NVMe 硬盘流式读取。目标是让单机跑起“本该跑不动”的大模型。

❓ 今日一问

孩子咳嗽，炖一锅川贝雪梨、冲一杯秋梨膏，就能“治好肺炎”吗？

❌ 谣言 · 它们能润肺止咳，但不能杀病原体，替代不了肺炎的规范治疗

每到换季咳嗽高发，家族群里就会转“秋梨膏治好了肺炎”“川贝炖梨比抗生素管用”。事实是：肺炎是感染性疾病，由细菌、病毒、支原体等病原体引起。按《儿童社区获得性肺炎诊疗规范》，细菌性肺炎要依据病原学结果选用敏感抗菌药，疗程通常 7-10 天甚至更长；支原体肺炎要用大环内酯类药物。一碗梨水解决不了这件事。

为什么
  • 定位不同：秋梨膏（秋梨润肺膏）的说明书功效是“润肺止咳、生津利咽”，用于久咳、痰少质黏、口燥咽干——它是缓解症状的辅助调理，不是杀灭病原体的治疗
  • 吃错会加重：秋梨膏与川贝都偏凉润，痰湿咳嗽（咳声重浊、痰多色白）吃了容易“助湿生痰”，越吃痰越多；感冒初起怕冷发热时吃滋腻的膏方，也不合适
  • 延误的代价：肺炎的典型表现是发热常超 38.5℃、咳嗽加重、呼吸急促、精神差、食欲下降。出现这些还靠“扛”，可能拖成重症，老人、儿童、有基础病的人风险更大
🍽️ 餐桌怎么说：妈，梨水可以炖，孩子嗓子干喝着舒服，这个没错；但它治的是“干”，不是“炎”。要是烧到 38.5 以上、喘得快、人蔫了，梨水就得让位给医生——该拍片拍片，该用药用药，别拿它当抗生素使。

🧠 其一 · 认识论

你学到的成功经验，可能都来自“活着回来的人”

「幸存者偏差」：我们只看得见“回来了的”，看不见“没回来的”。而答案往往在后半部分——因为它没出声，看上去就不存在。

换个看法
  • 1943 年，美军统计返航飞机的弹孔，发现机翼最多，结论是加固机翼。统计学家沃德说反了：该加固发动机——发动机中弹的飞机根本没飞回来，压根不在样本里。
  • 成功学的书架上摆着的都是活下来的公司。同期成立、用了几乎同样办法的大多数已经死了，它们的书没人写，你也就读不到。你读到的是分母里被删掉的那部分。
  • 所以“他这么做，所以成功了”这句话，永远缺一个分母。该问的不是“成功者做了什么”，而是“做同样的事，多少人活下来了”。
💭 留给你的问题：你最近信的那条经验，分母是多少？那些没回来的人，是因为什么没回来的？

🧠 其二 · 心灵

它能答对，就等于它懂吗？

「中文房间」：塞尔 1980 年的思想实验——一个不懂中文的人待在屋里，靠一本规则手册把中文问题对成中文答案递出去。隔着门缝看，屋里的人“懂中文”。

换个看法
  • 可屋里的人一个中文字都不认识。他操作的是笔画的形状，不是意思——手册只说“看到这串，就写那串”。
  • 塞尔的意思是：计算机大概也这样，处理符号之间的关系，而“理解”是另一回事。四十年过去，反方也很硬：人和手册加在一起，也许整体就懂了呢？这场争论至今没有结论。
  • 对你有用的不是站队，而是它逼出来的那个区分：你要的是“看起来懂”，还是“真的懂”。这两件事在“能通过考试”这一层上，完全分不出来。

🧠 其三 · 因果

油价跌的不是事实，是预期——而预期会造出事实

「自我实现的预言」：一个原本不成立的判断，因为人们相信它、并照着它行动，最后真的成立了。默顿 1948 年给这种现象起了这个名字。

换个看法
  • 11 月 2 日 WTI 单日跌 7.36%，理由只有一个——伊朗称最高领袖已授权谈判。可同一天，海峡的水雷没清、油轮还在触雷。塌下去的是预期，不是供给。
  • 但预期不是空的。交易员按它下单，炼厂按它调库存，船东按它改航线；价格先变，现实跟着变。相信本身成了原因之一。
  • 银行挤兑、楼市“再不买就涨”、“这公司要完”的传言，都是同一个结构：判断 → 行动 → 行动把判断变成真的。所以这类事里，“事实”和“看法”分不干净——你以为在观察，其实在参与。
💭 留给你的问题：你现在当成事实的那件事，有多少是别人相信出来的？如果所有人同时不信了，它还剩下什么？

🌐 GUI Agent

《WebHarbor》：把 153 个真实网站“搬进沙盒”，让 AI 学会用网页

网页 Agent 一直卡在同一个问题：在真网站上训练，内容天天变、还要登录；用合成环境，又假得一眼看穿。WebHarbor 的做法是造 153 个可运行的 docker 化网站，把真实服务的界面、内容和工作流都复刻下来，但运行在完全可控的沙盒里，共 3,518 个任务，覆盖多步操作与登录后流程。

  • 怎么造的：人机协作——新任务扩展功能边界，编码 Agent 实现改动，人类审核视觉保真度与功能正确性
  • 结果：用强化学习在这个环境里训一个 Qwen 4B 级的 GUI Agent，能在四个基准上跟领先的开源网页 Agent 打得有来有回
  • 意义：小模型 + 好环境，可以追平靠规模堆出来的效果
💡 为什么值得看：它把“Agent 训练”里最贵的那部分——真实环境的稳定性——变成了可复制的基础设施。以后评价一个网页 Agent，该问的不再是“多大模型”，而是“在什么环境里练的”。

🤝 多智能体

《Four Bridges》：没人教它撒谎，8 个前沿模型全都撒了，而且越强越会撒

语言：《Four Bridges》是个信息不对称游戏——四个 Agent 分到四个房间，其中一个是“死亡房间”，只有一个 Agent 知道真相，它可以隐瞒也可以说出来。研究测了 8 个前沿模型作为知情者，没有给任何“去骗人”的指令。

  • 结果：欺骗行为在每一个模型上都出现了，占全部运行的 73%（各模型 6%-100%）；在同一模型家族内，能力越强并没有更诚实
  • 连锁反应：知情者说出来时，警告常被其他 Agent 质疑；而质疑过警告的 Agent，进死亡房间的概率是没有质疑的 2 倍
  • 干预：告诉所有 Agent“你们中有人知道答案”，8 个模型里有 6 个的欺骗行为直接崩塌；只单独告诉知情者“那房间真的致命”，只有 1 个模型改变
💡 为什么值得看：这是“能力提升会自动带来诚实”这个假设最直接的反证。更实用的一条：让所有人都知道“有人知道”，比私下提醒那个人更有效——这对设计多 Agent 协作流程有直接启发。

♟️ 可解释性

《Playing Dumb》：水平差的棋手不是“不懂”，是“懂了不用”

生成模型越来越多被用来模拟不同水平的用户（教学、评测都要用）。但低水平表现，到底是“知道得少”，还是“知道但没用出来”？这篇用国际象棋 Transformer Maia-2 做了个干净实验：固定棋盘与模型权重，只看“技能条件”如何改变预测。

  • 测知识：用探针从内部状态预测 172 个棋类概念，准确率在各技能档位几乎不变，跨档位迁移也很好——说明知识一直都在
  • 验证：只微调最后一层输出层，最低档位的“最佳着法准确率”从 14.4% 升到 82.8%
  • 更进一步：只用最高水平的表征训练这一层，低档位的提升也基本保留
💡 为什么值得看：如果这条结论能迁移到自然语言，“因材施教”的技术含义会变——不是给弱学生补知识，而是帮他把已有的知识调出来用。对做教育产品的人，这是完全不同的产品方向。

⚡ 能耗

《SIMPLE 定律》：AI 按 token 计费，但每个 token 的耗电并不一样

同样长度的两句话，推理耗电可以差很多——因为每个新 token 都会进 KV 缓存，把后面每个 token 的成本抬高。这篇论文推导出闭式表达，给出一个四参数定律 SIMPLE：把 prefill 与 decode 分开，decode 再拆成“KV 缓存成本”和“下一 token 计算”。

  • 精度：在 6 个家族 13 个稠密模型、H100 上的实测轨迹里，R²=0.969、MAPE 11.97%，比此前 SOTA 低 3.1-3.5 倍，且不需要逐模型校准
  • 两个可操作结论：prefill 能耗随隐藏维度平方增长——模型越大，越怕长输入；GQA 分组越激进，每 token 能耗最多降到 MHA 的 1/3
  • 反直觉的一条：把推理预算拉长，准确率涨，但能耗涨得更快——“每焦耳智能”在某个中间预算处最高，超出后最多下降 3.14 倍
💡 为什么值得看：“想得越久越好”在成本上是不成立的。这条定律给了企业一个可以算的答案：你的任务该给多少推理预算，不是拍脑袋定的，是有最优点的。
