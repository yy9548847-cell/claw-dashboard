🧠 AI for Science

腾讯混元 Hyra 2.0：AI 不再“刷题解题”，改成自己造科研工具

11 月 2 日，腾讯混元发布 AI 科研系统 Hyra 2.0。研发重心从“用 AI 直接攻具体科学难题”，转向让通用 Agent 参与科学模型、研究工作流与软件工具的研发升级。

  • 三层架构：Overall 对齐人类研究目标，Mission 长期负责一个问题并判断路线取舍，Worker 独立读代码、做实验、分析失败，还能反过来质疑 Mission
  • 成果一：自训的蛋白质逆折叠模型 HyInv 只有 196 万参数，生成速度是 ProteinMPNN 的 57 倍
  • 成果二：量子纠错工具 HyQEC 构造的量子码，编码效率比 qLDPC Challenge 原榜首高约 48%
  • 成果三：数学工作流 HyProver 完成丘成桐圆周作用猜想等证明，并经过数学家核验
💡 解读：1.0 是“解出一道题”，一次性收益；2.0 是把方法沉淀成工具，让下游任务反复复用——这才是他们说的“智能复利”。这条比又一个参数纪录更值得记。

🛠️ 开源 Agent

DeepSeek 开源编码 Agent：Router 分派、Worker 隔离，GitHub 单日 +5600 星登顶

DeepSeek 以 MIT 许可开源编码智能体原型 dsh-superagent（v0.1.0）：Router 与用户对话并分派任务，Worker 在隔离会话里并发执行。团队同时提出“用 Router 替代会话”的思路，异步任务机制已实现但默认未开，分 off / observe / auto 三档。

  • 榜单：今日 GitHub 星标增量 +5,621，全天第一（总 12,756 星）
  • 配套动作：DeepSeek 宣布将全面开源内部推理框架，并同步开放编解码组件
  • 一个招聘信号：团队称模型、算法、基建的人手够了，缺的是产品经理和设计师——做 Agent 的瓶颈已经不在模型
💡 解读：开源的表面是代码，真正被分享的是“任务怎么分派、失败怎么隔离”这套方法论。对做 Agent 产品的团队，这比又一个模型发布更有参考价值。

❓ 今日一问

手机放枕边会致癌、家里有 Wi-Fi 睡觉必须关路由器，是真的吗？

❌ 谣言 · 手机、Wi-Fi 属于非电离辐射，正常使用不会像传言那样致癌

手机、Wi-Fi、微波炉、电吹风、电脑、电视产生的，主要是非电离辐射。它的能量远低于 X 光、CT 这类电离辐射，正常使用下不会像传言说的那样直接致癌、伤脑或破坏 DNA。真正需要关心的是产品是否合规、使用距离与时长，而不是把所有“辐射”都当洪水猛兽。

为什么
  • 能量差着量级：电离辐射能把电子从原子上“打”下来、损伤细胞；非电离辐射做不到这件事，这是两类辐射最本质的区别
  • 合规产品有上限：手机贴近头部通话时的电磁能量吸收率（SAR）受国标限值约束，合格产品在限值之内
  • “信号差更费电”是真的，但另一回事：信号弱时手机确实会提高发射功率，这和“致癌”没有因果关系；少数人主诉电磁场环境不适，但现有研究尚未证实与射频电磁场存在因果
🍽️ 餐桌怎么说：妈，手机别放枕头底下，不是因为致癌，是因为你会一直刷——蓝光和“再看一条”才是你睡不好的原因。路由器也不用天天拔，它那点功率还不如你床头那盏台灯。真要护着睡，就把手机放远一点、调成勿扰。

🧩 表征理论

《用 JEPA 证明并改进柏拉图表征假说》：把“不同模态终将殊途同归”从直觉变成定理

🧠 持续学习

《路由式持续学习》：给 Agent 的历史经验分簇，API 成本降 72%

Meta FAIR 提出的 Routed CL：把历史轨迹归入不同簇、每簇单独维护一套记忆；每次任务前由 LLM 路由器判断“这次该复用哪一簇，还是新建一簇”。核心优势是透明部署——不改动现有 Agent 的协作方式，只在上下文入口做一层适配。

  • 为什么需要：全留最完整但上下文与 API 成本高；全压成一种记忆又会丢掉只对特定任务有用的细节
  • 评测：CL-Bench 六个任务的 301 个实例 + τ³-Bench 的 97 个银行业多轮对话实例，交错排布、不给任务标签
  • 结果：据作者口径，API 成本可降低约 72%
💡 为什么值得看：“记忆”正在从“存更多”变成“存对路”。做客服、运维这类长期跑同一类任务的系统，这套分簇路由比简单加向量库更接近工程可用的答案。

🔧 权重编程

MIT CSAIL《权重空间编程》：模型直接读改自己的权重，改 0.016% 让数学能力涨 6 倍

论文提出 Weight-Space Programming：让前沿 LLM 把原始权重当成可读可改的代码，诊断故障并直接打补丁，不靠梯度、不靠反向传播、不靠大规模训练。实验里让 GPT-6 Astra 修改 Qwen3.5-0.8B 的权重，只动了 0.016% 的参数，MATH-500 从 7.9% 升到 48.1%，指令遵循最高提升 3 倍。

  • 怎么定位：Astra 在练习问题上用 50 次前向传播的预算找到了“推理循环”这个病根
  • 其他测试：只看权重就认出四个 Atari 游戏策略；给一条失败轨迹就修好卡在坡道的 PPO 车（改 3.5% 权重，成功率 100%）
  • 边界：目前是个案与早期证据，不是“以后不用训练了”
💡 为什么值得看：如果这条路走通，“修模型”会像“修 bug”一样便宜——小模型 + 精准打补丁，可能比换大模型更划算。对端侧和私有化部署，这是最值得跟的一条线。

🐕 1957·11·03

莱卡上天：第一个进入地球轨道的生命，只活了 5-7 小时

1957 年 11 月 3 日，苏联发射斯普特尼克 2 号，舱内是莫斯科街头的流浪狗莱卡，它成为第一个进入地球轨道的生命。这颗卫星从设计到发射只用了不到一个月——因为赫鲁晓夫要求赶在十月革命 40 周年前再放一颗，而且要带活物。它没有回收方案：当时的技术做不到。

  • 数据：卫星重 508.3 公斤，是首颗卫星的六倍；莱卡约三岁、六公斤，身上装着监测呼吸与心跳的传感器
  • 起飞时：心率从每分钟约 100 次飙到约 260 次，三小时后回落到 100 次左右
  • 真相：官方曾说它活了一周、安乐死；2002 年参与项目的科学家披露，热控系统因赶工有缺陷，莱卡在升空后 5-7 小时内因中暑与应激死亡
🎲 花边：选流浪狗的理由很“工程”：耐饿耐冷、需求少；选雌性是因为排尿不必抬腿，能省舱内高度。发射前三天，科研人员轮流把它带回家，和自家狗玩、吃一顿好的；关舱门时，几个人亲了它的鼻子。2008 年莫斯科为它立了纪念碑，NASA 把火星上一处采样点命名为“莱卡”。

🛰️ 1973·11·03

水手 10 号发射：人类第一次用“引力助推”赶路，第一次近距离看水星

🎲 花边：引力助推的意义常被低估：它让探测器“偷”行星的动量来加速，省下的不是一点燃料，而是整级火箭。今天所有飞往木星、土星的深空任务，走的都是水手 10 号验证过的这条路。
