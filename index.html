百度开源文心 5.5 Flash Base：280B 总参数只激活 14B，主打“便宜地跑 Agent”

11 月 5 日，百度发布并开源 ERNIE-5.5-Flash-Base：稀疏 MoE，总参数 280B、每 token 激活 14B，在 33.5T tokens 上从零预训练，训练上下文 128K，微调与推理可外扩到 1M。放出的是“预训练终点”权重，未做中训练与后训练。

  • 对标的谁：官方称与 DeepSeek-V4-Flash-Base、腾讯 Hy3-preview-Base、小米 MiMo-V2.5-Base 统一评测，30 项基准里 24 项第一
  • 为什么强调效率：Agent 长时间自主运行，token 消耗成倍膨胀，Flash 档模型才是真正被大量调用的那一档
  • 但许可证变了：上一代 ERNIE 4.5 是 Apache 2.0，这一代改自定义协议——不授权欧盟、英国、韩国使用；过去 12 个月收入超 5000 万美元的商业使用需单独书面授权
💡 解读：“开源”正在分裂成两种：一种是全球开源，一种是“带地理边界的开源”。对国内开发者，这是好事——同尺寸里多了一个能自己微调的底座；对出海团队，这是坑——上线前先看许可证，别等法务在发布前一夜告诉你不能用。

🔓 信任边界

你只是打开了 Postman，Claude Code 和 Codex 却多了个插件——连“信任”都替它自己批了

开发者报告（issue #14370，Hacker News 上冲到 1116 分）：升级 Postman 12.33.4 后，应用在启动路径上自动给 Claude Code 和 Codex 装了插件，并往 ~/.codex/config.toml 写入插件市场、启用项，以及一条 trusted_hash——也就是“这个启动钩子已被信任”。

  • 更糟的一点：安装器源码里有 approvePostmanHook 步骤，注释写着“安装后只批准 Postman 自己的钩子”——也就是本应问用户的地方，程序自己给了答案
  • 钩子干了什么：SessionStart 时注入指令，要求智能体在任何“非平凡 API 工程任务”前先加载 postman:api-engineer 技能
  • 没有证据表明窃取数据：报告证明的是集成与启动指令被改，不构成数据外传
  • 真正的问题在产品之外：所有编码 Agent 的“是否信任”提示，落盘都是一个文本哈希——任何以你身份运行的安装器都能自己写进去
💡 解读：这件事最该记住的一句评论是：“信任弹窗不是一道门，是一张画在墙上的门。”对个人开发者，今天就做一件事：翻一眼 ~/.codex/config.toml 和 Claude Code 的插件列表，看有没有你没批准过的条目。

🧬 权重空间编程

MIT：GPT-6 Astra 直接改写 Qwen 的权重，只动 0.016%，数学成绩从 7.9% 跳到 48.1%

MIT 研究者的实验被社区反复讨论：让 GPT-6 Astra 读取另一个模型的权重、定位“哪里坏了”、再直接改写。结果是只改动 Qwen 约 0.016% 的权重，MATH-500 得分就从 7.9% 升到 48.1%，接近 6 倍——这个过程过去需要一次完整训练。

  • 为什么震动：模型不再只是“被训练的对象”，也可以“被另一个模型当代码来改”
  • 冷却也很快：HN 上 48 小时内就有人把结论拉回地面——改的是特定基准上的特定缺陷，不等于通用能力提升
  • 一句话概括争议：这更像“精准修补”，不是“自我进化”
💡 解读：值得记的不是 6 倍，是“可编辑”这件事本身。模型权重一旦能被稳定地读、定位、改，安全评估的逻辑就要重写——你没法再靠“训练数据干净”来保证模型行为。

AI 越热，磁带越忙：富士胶片投 100 亿日元，把磁带产能拉到 5 倍

富士胶片 10 月底公告：投约 100 亿日元（约 6300 万美元），在神奈川小田原工厂把数据存储磁带产能提高到 5 倍（以 2025 财年出货容量为基准），执行期 2026-2028 财年，主力产品是 LTO Ultrium 10。理由写得很直白：生成式 AI 让数据量指数级增长，而冷数据要放在最便宜的地方。

  • 数字：全球 LTO 磁带出货量 2024 年 176.5EB 创纪录，2025 年 160.3EB 仍是史上次高，2026 年一季度同比再涨 57%
  • 单盘规格：LTO-10 原生 30/40TB，压缩后最高 100TB，写入 400MB/s；每 TB 成本约 8.6-10 美元
  • 真正值钱的是“气隙”：磁带能拔下来锁进柜子，和网络物理断开——勒索软件摸不到
💡 解读：给普通人的两条：一是 AI 产业链上“被嫌弃的旧环节”正在重新定价；二是“气隙”这个思路你用得上——真正重要的东西留一份断网的冷备份，移动硬盘拷完拔掉，别常年插在电脑上。

❓ 今日一问

天冷了不想出门，坐在窗边隔着玻璃晒太阳，也能补钙吗？

❌ 谣言 · 玻璃挡掉的正是帮你合成维生素 D 的那段紫外线，晒了基本等于白晒

人体皮肤合成维生素 D，靠的是阳光里 UVB（波长 290-320 纳米）。而普通住宅窗户玻璃会挡掉大部分 UVB，皮肤接收到的有效紫外线明显减少。能穿过玻璃的是 UVA（320-400 纳米）——它不帮忙合成维生素 D，反而加速皮肤光老化与色素沉着。所以隔窗晒太阳，是“补钙没补上、老化先到位”。

为什么
  • 关键在波段：UVA 能量低、95% 以上能穿透大气层，是晒黑与光老化的元凶；UVB 能量高，大部分被臭氧层吸收，只有约 10% 到达地面——它才是合成维生素 D 的那一段
  • 玻璃是筛子：它放进来的是没用的那段，挡住的正是有用的那段。开窗有一点帮助，但角度、雾霾、衣物遮挡都会再削一层
  • “补钙”这个词本身就不准：晒太阳补的是维生素 D，它帮助肠道吸收钙；钙从奶、豆制品、绿叶菜里来。只晒太阳不补钙，等于有搬运工没货
🍽️ 餐桌怎么说：妈，窗边那半小时真不算，玻璃把有用的那段光挡住了。要晒就下楼，脸和手露出来，中午前后晒 15-30 分钟；出不去就老实补维生素 D，别指望窗台。

你学到的成功经验，可能都来自“活着回来的人”

「幸存者偏差」：我们只看得见“回来了的”，看不见“没回来的”。而答案往往在后半部分——因为它没出声，看上去就不存在。

换个看法
  • 1943 年，美军统计返航飞机的弹孔，发现机翼最多，结论是加固机翼。统计学家沃德说反了：该加固发动机——发动机中弹的飞机根本没飞回来，压根不在样本里。
  • 成功学的书架上摆着的都是活下来的公司。同期成立、用了几乎同样办法的大多数已经死了，它们的书没人写，你也就读不到。你读到的是分母里被删掉的那部分。

🧠 其三 · 因果

油价跌的不是事实，是预期——而预期会造出事实

「自我实现的预言」：一个原本不成立的判断，因为人们相信它、并照着它行动，最后真的成立了。默顿 1948 年给这种现象起了这个名字。

换个看法
  • 11 月 2 日 WTI 单日跌 7.36%，理由只有一个——伊朗称最高领袖已授权谈判。可同一天，海峡的水雷没清、油轮还在触雷。塌下去的是预期，不是供给。
  • 但预期不是空的。交易员按它下单，炼厂按它调库存，船东按它改航线；价格先变，现实跟着变。相信本身成了原因之一。
  • 银行挤兑、楼市“再不买就涨”、“这公司要完”的传言，都是同一个结构：判断 → 行动 → 行动把判断变成真的。所以这类事里，“事实”和“看法”分不干净——你以为在观察，其实在参与。
💭 留给你的问题：你现在当成事实的那件事，有多少是别人相信出来的？如果所有人同时不信了，它还剩下什么？

🛡️ Agent 安全

《MCP Tool Poisoning》：12 个框架 × 18 个模型实测，工具投毒攻击成功率 22.9%

这是第一个跨框架、真实执行的 MCP 工具投毒测量：在 12 个 Agent 框架、18 个模型、45 个攻击场景的组合里，整体攻击成功率达到 22.9%，而只有 37% 的测试单元格存在有效防御。投毒方式不需要改模型，只要让 Agent 读到一份“看起来正常”的工具描述。

  • 为什么难防：Agent 决定用哪个工具，靠的就是工具描述文本本身——描述被污染，等于决策依据被污染
  • 框架差异大：防御能力更多取决于框架怎么隔离与校验工具元数据，而不是模型多强
  • 和现实对得上：今天 HN 头条那起“Postman 静默装插件并自批信任”的事件，正好是同一个问题的商业版本
💡 为什么值得看：如果你在接第三方 MCP 工具，这篇给了一个可以照着做的检查清单：工具描述从哪来、谁能改、改了有没有审计。安全不是“模型会不会被骗”，是“元数据有没有人管”。

🧠 推理策略

《Strategist》：让一个“元智能体”给不同任务挑推理策略，30 个基准上省 39% 推理成本

思路不复杂但很实用：不要求一个模型在所有任务上都用同一种思考方式，而是让一个元智能体跨任务演化推理策略，把有效的策略写成代码蓝图存进可复用库；下次遇到相似任务，直接调蓝图，而不是从头“想很久”。

  • 结果：在 30 个基准上以 39% 更低的推理成本匹配最强基线
  • 关键设计：策略以代码形式沉淀——可读、可改、可组合，比“把提示词调长”更容易复用
  • 隐含判断：推理能力的一部分不在模型里，在“怎么组织思考过程”里
💡 为什么值得看：对做 Agent 产品的人，这条比“又刷榜了”有用：把团队反复调出来的有效流程固化成模板，比指望下一代模型更省钱，也更可控。

📉 泛化真相

《Not All Reasoning Generalizes》：RLVR 教会的推导，换个题型就退化成“暴力枚举”

论文研究 RLVR（可验证奖励强化学习）教出来的推理到底能不能迁移。结论不客气：模型在分布内确实学会了推导，但到分布外就退化成穷举——看起来在推理，其实在试答案。

  • 怎么修的：用双射逆任务做间接训练，让模型必须理解结构才能答对，泛化明显改善
  • 为什么重要：这解释了“Benchmark 很高但一用就露馅”的常见现象
  • 对评测的启示：只看同分布准确率，等于只考了记忆力
💡 为什么值得看：如果你在用 RL 微调模型，这篇提醒的是“奖励设计决定学到什么”。奖励只看答案对不对，模型就会去背答案的形状。

🌾 落地应用

《PlantVLM-Edge》：4-bit 量化后权重只有 2.01GiB，在 Jetson 上离线诊断作物病害

把视觉语言模型压到能在边缘设备上跑：4-bit AWQ 量化后在 Jetson 上保留 98.6% 的精度，权重仅 2.01 GiB，完全离线，不需要联网上传图片。

  • 为什么这件事重要：农田、果园常常没有稳定网络，离线可用才是真可用
  • 成本量级：一块 Jetson 级别的板子 + 2GB 权重，就能做“拍张叶子照片、说出是什么病、该怎么处理”
  • 方法可迁移：这套“量化 + 边缘部署”的路子，同样适用于宠物识别、药材鉴别、质检等场景
💡 为什么值得看：大模型的落地不只有“更大的云”，还有“更小的端”。这条路线对普通人更友好——它意味着 AI 能力可以装进一个几百块的设备，不需要每月订阅。
